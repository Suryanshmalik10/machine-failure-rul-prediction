# Machine Failure & Remaining Useful Life (RUL) Prediction

A machine learning project that predicts the Remaining Useful Life (RUL) of turbofan engines using NASA's C-MAPSS FD004 dataset.

## Objectives
- Analyze engine sensor data and degradation patterns.
- Engineer features from time-series sensor readings.
- Train and compare regression models.
- Evaluate predictions using MAE, RMSE, R² and the NASA scoring function.
- Build a reproducible predictive maintenance pipeline.

## Tech Stack
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost (planned)

## Project Status
Initial setup — dataset loading, exploratory analysis and model development are planned.

## Dataset
NASA C-MAPSS, FD004 subset. See the [NASA Prognostics Center of Excellence Data Set Repository](https://www.nasa.gov/content/prognostics-center-of-excellence-data-set-repository/) for dataset access.

## Disclaimer
This is an academic machine learning project. Predictions are estimates and are not certified maintenance recommendations.
